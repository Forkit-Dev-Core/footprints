# Community highlights

[GitHub Discussions](https://github.com/Forkit-Dev-Core/footprints/discussions) is the place to ask questions, compare approaches, and share what you built. Workshops, learning groups, demos, and independent experiments are all welcome. Use [Issues](https://github.com/Forkit-Dev-Core/footprints/issues) when a post turns into a specific change to track.

When sharing a highlight, include:

- **What you explored:** A short description of the question or goal.
- **What you learned:** A finding, tradeoff, or open question that others can use.
- **How to try it:** A link to a public demo, writeup, pull request, or reproducible example.
- **What’s next:** A link to a follow-up issue, if there is one.

Share only material you have permission to publish. Use the simulated discovery page or a fresh registry containing only synthetic passports. Before sharing a screenshot, video, or log, remove repository names and remote hosts, account names, paths, device identifiers, real passport IDs, and file fingerprints. Keep raw scan history and registry files out of public posts. Maintainers can feature reproducible posts in Discussions.

## Try the Windows community preview

[Release notes](https://github.com/Forkit-Dev-Core/footprints/releases/tag/v0.1.0-preview.3) · [Windows x64 ZIP](https://github.com/Forkit-Dev-Core/footprints/releases/download/v0.1.0-preview.3/Footprints-Windows-x64.zip) · [SHA-256 file](https://github.com/Forkit-Dev-Core/footprints/releases/download/v0.1.0-preview.3/Footprints-Windows-x64.zip.sha256)

Extract the whole ZIP and double-click `Start Footprints.cmd` without elevation. Keep the launcher window open. Try scanning a supported installation, creating its passport, and rechecking the record ID and installation fingerprint. This is a preview; read the release notes for coverage and limitations.

Please share reproducible feedback in Issues: release tag, Windows version, steps, expected result, and observed result. Use synthetic evidence and inspect attachments before posting. A successful check is not a software safety certification.
