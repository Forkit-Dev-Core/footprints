# Footprints Discovery

Footprints Discovery is a Forkit community project for exploring how evidence can identify AI tools, runtimes, and models. The starter shows how a matcher handles different signal types, duplicate evidence, and near matches.

## Try the starter

Download or clone this repository and open `index.html` in a browser. The dashboard shows three findings from fictional data. It runs offline, does not scan your device, and does not send any data.

To run the checks, install Node.js 24 and run `node --test` from the repository root. There are no package dependencies.
